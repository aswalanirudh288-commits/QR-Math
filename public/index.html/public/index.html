QR Code Mathematics Model

You just scanned a QR code that was built by hand. Every square was cut from black chart paper and fixed on a thermocol base — no printer involved.

Animated 25 × 25 grid. The real model has 625 squares.

How a QR code works

A QR code is a square grid of tiny squares called modules. Each module is either black (1) or white (0), so the whole code is just a long string of binary digits.

Storing a link

Each letter of a web address has a number code. Those numbers become bits, and the bits fill the grid in a zigzag path from the bottom-right corner.

Scanning

A phone camera finds the three big corner squares, which tell it the code’s size and which way is up. Then it reads each module as black or white and turns the bits back into text.

Error correction

Extra bits, made with a branch of algebra called Reed–Solomon codes, are added. They let the phone rebuild the data even if part of the code is dirty or damaged — from about 7% up to 30% depending on the level.
25 × 25 = 625 modules

A 25 × 25 code is called Version 2. It can hold roughly 14 to 32 characters, depending on the error-correction level. That is why the web address on this model is so short.
